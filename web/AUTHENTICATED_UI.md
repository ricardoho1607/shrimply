# Authenticated Web UI Standard

Applies only to `/dashboard/**`. Public landing, download, SEO, and promotional pages are excluded.

- Page spacing: 16px desktop, 12px mobile; content max-width 1200px where appropriate.
- Cards: 16px radius, compact 12–16px padding, subtle border/shadow, no decorative lift beyond 1px.
- Toolbars: 40px controls, 10px padding, clear hover/focus states.
- Type: 10px uppercase labels, 12–14px body/control text, 14–17px headings, readable metric hierarchy.
- Actions: Shrimply navy for enabled primary actions; neutral grey for unavailable actions; no landing-page gradients.
- Modals/drawers: compact headers, scrollable bodies, persistent action footers, no redundant decorative icons.
- Mobile: single-column cards, paired short fields where readable, no horizontal page overflow, drawer width at most 78vw.
